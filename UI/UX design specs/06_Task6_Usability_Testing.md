# Task 6 – Usability Testing (15 Points)

Personal Budget Manager (WAIS) · Lab 5

**Objective (from the lab sheet):** Evaluate the usability and navigation efficiency of the proposed interface.

**Expected output:** Usability testing report and recommendations.


Ask at least two classmates to act as the user, without help. Scenario: "You spent ₱180 on lunch today. Log it as Food & Dining, check the details, save it, then find how much you have spent on Food & Dining this month." Start from Home. The shortest path to the Saved screen is 5 clicks (+, Next: Choose Category, Food & Dining, Next: Review, Confirm And Save); one more click on See Where It Went reaches the Summary. The prototype's Test mode panel counts clicks and time for you. As a second task, ask them to open Manage Categories, add a Pets category with a ₱800 limit, set the Food & Dining limit to ₱3,000, save, and then delete Pets.

| Evaluation item | Target | Tester 1 | Tester 2 |
| --- | --- | --- | --- |
| Completed the scenario without help | Yes |  |  |
| Clicks to reach Saved | 5 |  |  |
| Time to reach Saved | Under 30 s |  |  |
| Found the Food & Dining total in Summary | Yes |  |  |
| Added and deleted the Pets category without help | Yes |  |  |
| Navigation difficulties |  |  |  |
| Suggested improvements (at least two overall) |  |  |  |

Watch for: whether testers notice the error text when Next is blocked, whether the + button in the lower right is found, whether swiping the heatmap sideways is discovered, whether Manage Categories is found on Summary without a hint, whether the Move transactions first dialog is understood, and whether the emoji make categories easy to pick.
